# Pixel Trade Journal

I want you to build me a trading journal with a pixel art theme. I want it to have a calendar view where the total number of my trades and PnL for the each day are displayed. When I click on a certain day, it will show a more detailed view of my trades. It should have a form where I can input my trades. Is it also possible to just submit a screenshot of my trades and the app will automatically fill out the form fields?
